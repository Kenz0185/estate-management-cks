# Estate Management System — PT Citra Kenyalang Sakti

Prototipe HTML, CSS dan JavaScript dengan data contoh. Data input tersimpan hanya di browser masing-masing; belum menggunakan database bersama atau login server.

## Publikasi GitHub Pages
1. Unggah semua file dalam folder ini ke root repositori (jangan unggah ZIP).
2. Buka Settings > Pages.
3. Pilih Deploy from a branch, branch main, folder /(root), lalu Save.
